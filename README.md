## 遊び方

1. 上の[ゲームURL](https://mylifereading6666-oss.github.io/Aev-Battle/)をブラウザで開きます。
2. 最初の画面で、使いたいキャラクター（AEV / VOLT / MEDIC / NOVA）を選択します。
3. 「BOTバトル」を選び、「戦闘開始」を押します。
4. 移動しながら敵の攻撃を避け、通常攻撃・固有スキル・必殺技を使って戦います。
5. 体力がなくならないように注意しながら、敵の撃破やジェムの収集を目指してください。

初回起動時は、ゲーム本体と3D表示用ライブラリを読み込むため、インターネット接続が必要です。画面が完全に読み込まれるまで待ってください。

## 操作方法

### PC（キーボード・マウス）

| 操作 | 方法 |
| --- | --- |
| 移動 | **W / A / S / D** |
| 狙う方向を変える | マウスを動かす |
| 通常攻撃 | マウス左クリック |
| 固有スキル | **E** |
| 必殺技 | **Q** |
| 音のON / OFF | 画面右側の「音 ON / 音 OFF」ボタン |

### スマートフォン・タブレット（タッチ操作）

| 操作 | 方法 |
| --- | --- |
| 移動 | 画面左下のスティックを動かす |
| 向きを変える | 画面右側をドラッグ |
| 通常攻撃 | 「攻撃」ボタン |
| 固有スキル | **SKILL** ボタン |
| 必殺技 | **SUPER** ボタン |
| 音のON / OFF | 画面右側の「音 ON / 音 OFF」ボタン |

スキルにはクールダウンがあります。必殺技はゲージが100%になると使用できます。使用できないときは、クールダウンやゲージを確認してください。

## キャラクター

ゲーム開始前に、4人のキャラクターから選べます。キャラクターごとに体力・移動速度・攻撃力・射程やスキルが異なります。

| キャラクター | 特徴 |
| --- | --- |
| **AEV** | バランス型。エナジーダッシュとエナジーバーストを使う |
| **VOLT** | 素早さを活かすタイプ。ライトニングとサンダーストームを使う |
| **MEDIC** | 回復が得意。リカバーとヒーリングフィールドを使う |
| **NOVA** | プラズマ系の攻撃が特徴。プラズマボムとノヴァインパクトを使う |

キャラクターの能力値やゲームバランスは、開発中に変更される場合があります。

## 勝利条件とゲームの流れ

- 敵BOTを倒すと撃破数が増えます。
- アリーナ内のジェムを集められます。
- 体力がなくなると敗北になります。
- 制限時間やゲーム内の目標達成状況によって勝敗が判定されます。
- 戦闘中は敵の攻撃を避け、障害物に気をつけながら立ち回りましょう。

現在のゲームには、BOTとの戦闘、敵の飛び道具、ジェム収集、体力・シールド・必殺ゲージ表示、勝敗演出、効果音が実装されています。ゲーム内容は試作段階であり、細かな挙動や勝敗条件は今後変更される可能性があります。

## オフラインプレイ

Aev Battleは、初回の読み込み後に同じブラウザで再び開いたとき、オフラインでも起動できるようService Workerによるキャッシュに対応しています。

**オフラインで遊ぶための手順**
1. インターネットに接続した状態で、[ゲームURL](https://mylifereading6666-oss.github.io/Aev-Battle/)を開きます。
2. ゲームの読み込みが完了するまで待ちます。
3. ページを一度開いたブラウザを使い、次回は機内モードなどネット接続のない状態でURLを開いて動作を確認します。
4. オフラインで起動しない場合は、ネット接続を戻してページを再読み込みし、キャッシュが完了してから再度試してください。

### オフライン利用時の注意

- 初回アクセスと必要ファイルの取得にはインターネット接続が必要です。
- キャッシュは、最初に利用した端末・ブラウザごとに保存されます。別の端末や別ブラウザに自動で引き継がれるわけではありません。
- ブラウザのデータ削除、キャッシュ消去、保存領域の整理などで、オフライン起動に必要なファイルが消える場合があります。
- 端末やブラウザの仕様によっては、オフライン起動が保証されない場合があります。
- 現在オフラインで利用できるのはBOTバトルです。オンライン対戦は利用できません。
