# Aev Battle

**Aev Battle** は、スマートフォン・タブレット・PCのブラウザで遊べる、オリジナルの3Dアリーナバトルゲームです。4人のキャラクターから1人を選び、BOTと戦いながら敵を倒してジェムを集めます。

- **ゲームURL：** https://mylifereading6666-oss.github.io/Aev-Battle/
- **ソースコード：** https://github.com/mylifereading6666-oss/Aev-Battle
- **不具合報告：** https://github.com/mylifereading6666-oss/Aev-Battle/issues

ゲーム内の「📘 ルール・仕様」ボタンからも、勝利条件、操作方法、各キャラクターのSkill・必殺技、クレジット、ライセンスを確認できます。

## 遊び方

1. ゲームURLをブラウザで開き、読み込みが完了するまで待ちます。
2. AEV / VOLT / MEDIC / NOVAからキャラクターを選びます。
3. **BOTバトル**を選んで「戦闘開始」を押します。
4. 移動して敵の攻撃を避け、通常攻撃・固有スキル・必殺技を使います。
5. ジェムを集めるか、敵を倒すなどして勝利条件を達成してください。

## ルールと勝利条件

- **ジェム10個を集める：** 勝利。
- **敵BOTを8体倒す：** 勝利。
- **3分の制限時間：** 時間切れ時に敵を4体以上倒している、またはジェムを5個以上持っていれば勝利。それ以外は敗北。
- **体力が0になる：** 敗北。
- **安全エリア：** リングの外にいると継続ダメージを受けます。リングは時間経過で縮小します。
- **シールド：** ダメージはシールドから消費され、シールドがなくなると体力が減ります。

### 攻撃・必殺ゲージ

- 通常攻撃は約0.34秒ごとに使用できます。射程内にいる最も近い敵を狙います。
- 通常攻撃を1回行うと必殺ゲージが8%増加します。
- 敵を1体倒すと必殺ゲージが12%増加し、その位置にジェムが出現します。
- ジェムを1個拾うと必殺ゲージが5%増加します。
- 必殺ゲージの上限は100%。必殺技を使うと0%に戻ります。
- 敵BOTはプレイヤーへ近づき、一定距離から赤い飛び道具で攻撃します。移動して避けてください。

## インターネット接続なしで遊ぶ方法（事前準備が必要）

Aev Battleは、**最初にインターネット接続中に必要なゲームファイルを読み込んでキャッシュしておけば、同じ端末・同じブラウザでオフライン起動できる場合があります。** まだ一度も開いたことのない端末で、最初から完全にオフラインで起動することはできません。

### 初回だけ必要な準備

1. Wi-Fiまたはモバイル通信に接続します。
2. [Aev Battleのゲームページ](https://mylifereading6666-oss.github.io/Aev-Battle/)を、普段オフラインで使う予定のブラウザで開きます。
3. ゲーム画面が完全に読み込まれるまで待ちます。初回は3D表示用のThree.jsライブラリなども取得します。
4. ページを一度再読み込みし、ゲームが正常に起動することを確認します。Service Workerの登録とキャッシュ保存が完了するまで、通信を切らずに少し待ってください。
5. そのブラウザを閉じてからもう一度ゲームページを開き、正常に起動することを確認します。

### インターネットを切って遊ぶ

1. 上記の準備が終わっていることを確認します。
2. 端末の機内モードをオンにするか、Wi-Fiとモバイルデータ通信をオフにします。
3. **同じ端末・同じブラウザ**で、Aev BattleのURLを開き直します。
4. ゲームが起動したら「BOTバトル」を選んで遊びます。オンライン対戦は現在対応中のため、オフラインでは遊べません。

### 起動できない場合

- いったんインターネット接続を戻し、ゲームページを開いて読み込み完了まで待ってから、もう一度試してください。
- ブラウザのキャッシュ・サイトデータを消去した場合や、プライベート／シークレットモードを使った場合は、必要なファイルが保存されずオフライン起動できないことがあります。
- ブラウザや端末の設定によっては、Service Workerやキャッシュが制限されるため、オフライン起動を保証できません。
- 別の端末や別のブラウザにはキャッシュは自動で引き継がれません。それぞれでオンライン中に初回準備を行ってください。
- ホーム画面への追加はショートカットを作る方法であり、それだけでオフライン対応が保証されるわけではありません。

**大切な注意：** この方法は、必要なファイルが正常にキャッシュされている場合に限り利用できます。実際にネットを切る前に、使用する端末で機内モードでの起動テストをしてください。オフラインで遊べるのはBOTバトルです。
