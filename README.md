# Aev Battle

スマートフォン・PCのブラウザで遊べる、Three.js製の3Dアリーナバトルゲームです。

## 現在の機能
- キャラクター選択：AEV / VOLT / MEDIC / NOVA
- キャラクターごとの体力・移動速度・攻撃力・射程
- 通常攻撃、固有スキル、ゲージ式の必殺技
- 移動・攻撃に合わせた簡易キャラクターアニメーション
- BOTとの戦闘、敵撃破、ジェム収集、時間切れ、体力切れによる勝敗判定
- スマートフォン用スティックと攻撃・スキル・必殺技ボタン
- Supabase Realtimeを使ったルーム・プレイヤー位置・攻撃イベントの試験的同期
- フレンドコードのローカル保存とルームコード共有

## プレイ方法
1. 公開URLを開き、キャラクターを選択
2. BOTバトルなら「戦闘開始」を押す
3. PC：WASDで移動、マウスで照準、クリックで通常攻撃、Eで固有スキル、Qで必殺技
4. スマートフォン：左スティックで移動、右側をドラッグして向きを変更、攻撃・SKILL・SUPERボタンを使用
5. ジェム10個、敵8体撃破、または制限時間終了時の条件で勝敗が決まります

## オンライン試作の設定
オンラインモードを使うには、自分で用意したSupabaseプロジェクトの **Project URL** と **anon / publishable key** をゲーム画面に入力し、接続後に部屋を作るか部屋コードで参加してください。

**service_roleキーや秘密鍵は絶対に入力・公開しないでください。**

現段階のオンライン機能は試作です。ルーム内のプレイヤー表示と位置・攻撃イベントを同期しますが、完全な競技用オンライン対戦ではありません。フレンドコードはこのブラウザのlocalStorageに保存されるだけで、アカウント間で永続共有されません。公開運用には認証、データベース側のアクセス制御、サーバー権威型の勝敗検証、切断処理、不正対策が必要です。

## GitHub Pagesで公開
1. GitHubリポジトリの **Settings** を開く
2. **Pages** を開く
3. **Build and deployment** の **Source** で **Deploy from a branch** を選択
4. Branchを **main**、フォルダを **/(root)** にして **Save**
5. 数分待ち、Pages欄に表示されたURLを開く

## 技術
- HTML / CSS / JavaScript modules
- Three.js 0.160.0（jsDelivr CDN）
- Supabase JavaScript SDK（オンライン試作時のみ）
- ビルド手順不要。index.htmlをルートに置いて公開します。

## 現在の制限
コードはGitHubに保存されていますが、スマートフォン実機・複数端末でのオンライン動作確認はまだ完了していません。外部CDNに接続できるブラウザが必要です。
